# Reality VPN — Android 8.0.0

Отдельный Gradle-проект и отдельные APK для **Android 8.0.0 / API 26**.

## Готовое приложение

Скачать APK на GitHub: [релиз клиентов Reality VPN 1.0.3](https://github.com/bulahkirill68-byte/MyVPNAdmin/releases/tag/clients-v1.0.3).

Основной файл для установки:

**`releases/RealityVPN-Android8-1.0.3.apk`**

Это универсальный APK для ARM32, ARM64, x86 и x86_64. Если архитектура устройства неизвестна, используйте его.

Также в `releases/` находятся APK меньшего размера для конкретной архитектуры:

- `RealityVPN-Android8-1.0.3-armeabi-v7a.apk` — 32-битные ARM-устройства.
- `RealityVPN-Android8-1.0.3-arm64-v8a.apk` — 64-битные ARM-устройства.
- `RealityVPN-Android8-1.0.3-x86.apk` — 32-битные Intel-устройства и эмуляторы.
- `RealityVPN-Android8-1.0.3-x86_64.apk` — 64-битные Intel-устройства и эмуляторы.

SHA256 и размеры находятся в `releases/checksums.json`.

## Установка и использование

1. Отключите работающее VPN-подключение.
2. Перенесите универсальный APK на Android 8.0.0 и установите. При необходимости разрешите установку из выбранного источника.
3. Приложение называется **Reality VPN · Android 8**. APK подписан прежним ключом, `applicationId` сохранён: его можно установить поверх текущей версии Reality VPN 1.0.3 с сохранением профилей. Удалять приложение предварительно не нужно.
4. Выберите или импортируйте VLESS REALITY ссылку и нажмите **Подключить VPN**. Подтвердите системное разрешение VPN.
5. Для добавления плитки откройте шторку → редактирование / карандаш → перенесите **Reality VPN** к активным кнопкам. В настройках приложения есть соответствующая инструкция.

Сохранены анимации, счётчики и скорости, уведомление с трафиком и кнопкой остановки, выбор приложений с иконками и исправленное разделение DNS для Яндекса/российских сайтов. Профили защищены Android Keystore. UUID и реальные серверные доступы в сборку не встроены.

## Особенности порта

- `minSdk = 26`, `targetSdk = 26`. `compileSdk = 35` нужен только инструментам сборки и не повышает требование к устройству.
- Собственный манифест для Android 8: VPN-служба и Quick Settings без требований к разрешениям/типам foreground-служб новых Android.
- Уведомления используют каналы Android 8 и флаги `ongoing` / `no-clear`.
- Добавление плитки на Android 8 выполняется через редактирование шторки; системный диалог добавления плитки Android 13+ не вызывается.
- Java-код и ресурсы подключены из `../android/app/src/main/`, чтобы сохранять общие исправления протокола, интерфейса и DNS. Этот каталог — отдельный проект сборки, но для его пересборки нужен соседний основной Android-проект.
- Официальный `AndroidLibXrayLite 26.11.9` имеет минимум API 24; в этом порте используются все четыре предоставляемые архитектуры.

## Проверки

Прошли 10 тестов: парсер VLESS, DNS/routing и статистика плюс четыре Robolectric-проверки непосредственно на API 26 — запуск интерфейса, уведомление с трафиком, запуск настройки через плитку и инструкция добавления плитки. Также прошли `lintRelease`, проверка подписи и выравнивания всех пяти APK. `aapt` подтверждает минимальную и целевую версии 26 и четыре ABI в универсальном APK.

Реальное подключение к серверу на физическом Android 8.0.0 устройстве пока не проверено.

## Пересборка

Нужны JDK 17, Gradle 8.13, SDK platform 35 / build-tools 35.0.0 и зависимости основного Android-проекта.

Из корня репозитория:

```powershell
python vpn-client/scripts/prepare_android.py
python vpn-client/scripts/create_android_key.py
```

Задайте `JAVA_HOME` и `ANDROID_HOME`. Из `vpn-client/android-8`:

```powershell
gradle --no-daemon --console=plain testDebugUnitTest assembleRelease lintRelease
```

Затем из корня репозитория:

```powershell
python vpn-client/scripts/collect_android8.py
```

По умолчанию проект использует существующий `../android/signing.properties` и тот же ключ подписи. Собственный `android-8/signing.properties` имеет приоритет; путь `storeFile` разрешается относительно папки этого файла. Ключи и пароли исключены из Git.
