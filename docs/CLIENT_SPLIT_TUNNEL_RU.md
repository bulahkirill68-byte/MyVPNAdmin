# Россия напрямую: сайты, сервисы, приложения

## Применить к сайтам и соединениям приложений

1. Создайте пользователя, оставьте профиль **Россия напрямую**.
2. Откройте карточку доступа → **Клиентский JSON с маршрутизацией**. Файл содержит секрет UUID, передавайте приватно.
3. В совместимом v2rayNG/v2rayN выберите импорт **custom configuration / пользовательской конфигурации Xray** и загрузите полный JSON. Это не обычная ссылка-подписка.
4. Обновите GeoIP/GeoSite в клиенте. Нужны `geoip:ru`, `geoip:private`, `geosite:category-ru` (стандартные сокращённые базы некоторых сборок могут не содержать category-ru — используйте expanded geosite).
5. Запустите этот профиль. RU домены/IP и перечисленные российские международные домены идут через **локальный direct**, остальные TCP/UDP — через VLESS REALITY.

Базовый fallback включает .ru/.su/.рф, Yandex/yastatic, VK/userapi, Mail/OK, Госуслуги, Сбер, Т-Банк, Ozon/Ozon CDN, Wildberries/WB. Основное покрытие меняющихся адресов обеспечивает актуальная GeoSite/GeoIP клиента. Исключения администратора/пользователя могут намеренно иметь более высокий приоритет, чем пресет.

DNS в полном JSON: Cloudflare DoH по HTTPS с локальным вызовом вне прокси. Он может видеть DNS-запросы; это не анонимный DNS. При недоступности провайдера выберите рабочий доверенный DoH, сохранив отсутствие циклического проксирования DNS.

## Полностью исключить российские приложения Android

Доменная маршрутизация охватывает запросы приложений к известным доменам/IP. Однако российское приложение может обращаться к иностранному CDN, аналитике или неизвестному IP: такой трафик по общей политике может попасть в VPN. Для исключения **всего приложения**:

1. Откройте v2rayNG → Settings → Per-app proxy / Прокси для приложений.
2. Включите режим **bypass / исключать выбранные приложения** (название зависит от версии; внимательно проверьте инверсию списка).
3. Выберите установленные российские приложения: банковские, Госуслуги, Яндекс, VK, Ozon/Wildberries и прочие нужные вам.
4. Перезапустите VPN-профиль. Эти приложения должны выходить напрямую через оператора/Wi-Fi, в том числе на зарубежные адреса.

Список нельзя достоверно сформировать на VPS: сервер не знает установленные пакеты и не управляет Android VPNService. Обычная VLESS-подписка, QR и серверные routing rules его не меняют. На Windows TUN/per-app настройки также зависят от клиента; обычный системный HTTP/SOCKS proxy не перехватывает все приложения.

## Проверка

Откройте зарубежный IP-check сервис через профиль — ожидается IP VPS. Временно добавьте отдельный проверочный адрес в локальные direct-исключения и убедитесь, что он видит IP оператора/Wi-Fi. Для российских сервисов используйте журналы маршрутов клиента: срабатывание direct должно происходить **на клиенте**, а не на VPN-VPS. Серверный direct не возвращает трафик к домашнему российскому IP.

Гарантировать обход VPN абсолютно для всех «российских сервисов» по национальности компании невозможно: базы отстают, CDN общие, DNS/IPv6/QUIC и версии клиентов различаются. Per-app bypass — правильный механизм для полного исключения конкретных приложений.
